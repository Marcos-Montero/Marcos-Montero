<!-- How I lead -->
<h2>🧭 How I lead</h2>

<ul>
  <li><b>People</b>: recruit well, set clear expectations, 1:1s, growth plans, fair reviews, succession.</li>
  <li><b>Delivery</b>: roadmaps, capacity planning, risk/dependency management, visible comms, predictable execution.</li>
  <li><b>Quality</b>: design systems, testing strategy (unit/integration/E2E), CI/CD, perf budgets (LCP/TTI), SLOs & postmortems.</li>
  <li><b>Collaboration</b>: tight loop with PM/Design/Marketing; data-informed decisions.</li>
</ul>

<blockquote>
  I prefer <b>documents over meetings</b>, <b>design reviews over surprises</b>, and <b>small safe releases over heroics</b>.
</blockquote>
